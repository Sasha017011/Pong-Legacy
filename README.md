# Pong Legacy

Классический ремейк аркадной игры Pong 1972 года, созданный на движке **Godot 4.8**.

## Особенности проекта
* **Встроенный ИИ-соперник:** компьютерный оппонент отслеживает позицию мяча по оси Y и реагирует на изменение траектории.
* **Ретро-стилистика:** визуал в духе оригинального аркадного автомата Atari (пиксельный шрифт 70-х, монохромная графика).
* **Физика и звук:** отскок мяча с изменением угла, звуковые эффекты ударов и забитых голов, счетчик очков на базе `CanvasLayer`.

## Управление
* **Движение ракетки вверх / вниз:** `Стрелка вверх` / `Стрелка вниз`

## Как запустить
1. Скачайте готовый билд для Windows во вкладке **[Releases](../../releases)** справа.
2. Распакуйте архив и запустите `PongLegacy.exe`.
