# Pong Legacy

Классический ремейк аркадной игры Pong 1972 года, созданный на движке **Godot 4.8**.

## Особенности проекта
* Ретро-стилистика в духе оригинального автомата Atari (аутентичный пиксельный шрифт, монохромная графика).
* Реализована физика отскока мяча с изменением угла в зависимости от точки удара о ракетку.
* Звуковое сопровождение (отскок от стен, удар о ракетку, забитый гол).
* Счетчик очков и UI на базе `CanvasLayer`.

## Управление
* **Игрок 1 (левая ракетка):** `W` / `S`
* **Игрок 2 (правая ракетка):** `Стрелка вверх` / `Стрелка вниз`

## Как запустить
1. Скачайте готовый билд для Windows во вкладке **[Releases](../../releases)** справа.
2. Распакуйте архив и запустите `PongLegacy.exe`.
